# 🚀 Java Core Foundations — BroCode Java Playlist (Completed)

## 📘 Overview
This repository marks the completion of the **BroCode Java full playlist (~12 hours)**.  
The goal of this phase was **not mastery**, but to build **strong Java fundamentals**, understand core language concepts, and apply them through **hands-on mini-projects**.

This phase established the foundation required for:
- Data Structures & Algorithms (DSA) in Java

---

## 🧠 What Was Covered

### 🔹 Core Java Fundamentals
- Variables, data types, operators
- Control flow (`if`, `switch`, loops)
- Methods and method overloading
- Input handling using `Scanner`

### 🔹 Object-Oriented Programming (OOP)
- Classes & objects
- Constructors
- Inheritance
- Method overriding
- Interfaces vs abstract classes
- Composition (PART-OF relationship)
- Anonymous classes

### 🔹 Collections & Generics
- `ArrayList`
- `HashMap`
- Iteration (`for-each`, `keySet`)
- Java Generics (`<T>`, `<T, U>`)
- Type safety and reusable code

### 🔹 Enums
- Enum constants
- Enums with fields, constructors, and methods
- `switch` with enums
- `valueOf()` and exception-safe enum parsing

### 🔹 Exception Handling
- `try`, `catch`, `finally`
- Multiple catch blocks
- Checked vs unchecked exceptions
- Exception-safe user input and file handling

### 🔹 File & Resource Handling
- Reading and writing files
- Try-with-resources
- Audio playback using `Clip` and `AudioSystem`

### 🔹 Date & Time API
- `LocalDate`, `LocalTime`, `LocalDateTime`
- `DateTimeFormatter`
- Parsing and formatting date/time values

### 🔹 Threading & Concurrency (Basics)
- Thread lifecycle
- `Runnable` interface
- `Thread.start()` vs `run()`
- Daemon threads
- `join()`
- Background task execution
- Limitations and real-world cautions

## 🎯 Key Takeaways
- Java is verbose by design — clarity over shortcuts
- OOP is about **modeling reality**, not just syntax
- Threads must be handled carefully (daemon vs non-daemon)
- `System.exit()` works but is dangerous in real applications
- Foundations matter more than frameworks at this stage
